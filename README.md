# Julieta Sartori · Artista y Productora de eventos

Landing page estática de Julieta Sartori, cantante y productora de eventos en Buenos Aires.

- `index.html`: la página completa (HTML + CSS + JS del carrusel, sin dependencias).
- `video-artista.mp4`, `video-productora.mp4`: loops de la portada.
- `*.jpg`: retrato, pósters de los videos y fotos de producción.

## Publicar en Netlify
Conectar este repositorio en Netlify (Add new project → Import from Git). No requiere build: el directorio de publicación es la raíz.
