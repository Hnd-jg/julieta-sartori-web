# Julieta Sartori · Artista y Productora de eventos

Landing page estática de Julieta Sartori, cantante, compositora y productora de eventos en Buenos Aires.

## Estructura
- `index.html`: contenido de la página.
- `css/styles.css`: estilos.
- `js/main.js`: portada interactiva (el rol hacia donde va el cursor se expande), carrusel y animaciones de scroll.
- `js/gsap.min.js`, `js/ScrollTrigger.min.js`: GSAP 3, incluido localmente.
- `img/`: fotos optimizadas para web (sin metadatos).
- `video-artista.mp4`, `video-productora.mp4`: loops de la portada.

## Publicar en Netlify
Publicado en https://julietasartori.netlify.app (Netlify conectado a este repositorio: cada push a main se publica solo). No requiere build: el directorio de publicación es la raíz.
